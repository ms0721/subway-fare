# 北京地铁票价计算器 | Beijing Subway Fare Calculator

🚇 按自然月累计消费，自动匹配北京地铁优惠档次（八折/五折），月底清零。

## 版本说明

| 版本 | 说明 |
|------|------|
| **v1.0** | 基础版 — 固定票价 7 元，按日期累计计算优惠 |
| **v1.2** | 增强版 — 自定义票价、排除法定休息日、调休、三语切换、优惠门槛预估 |

## v1.2 功能

- 💵 **自定义票价** — 支持任意单程全价票价输入
- 📅 **排除法定休息日** — 自动跳过周末 + 法定节假日
- 🔄 **调休上班日** — 可选考虑中国调休上班日
- 🎯 **优惠门槛预估** — 计算距八折/五折还需几天
- 🌐 **三语切换** — 简体中文 / 繁體中文 / English
- 📊 **累计进度条** — 可视化当月消费距 ¥400 封顶的进度

## 北京地铁优惠规则

| 累计消费 | 折扣 | 
|----------|------|
| ¥0 – ¥100 | 全价 |
| ¥100 – ¥150 | 八折（80%） |
| ¥150 – ¥400 | 五折（50%） |
| ¥400 以上 | 恢复全价（封顶） |

每自然月月底清零，下月重新计算。
